# Campus Care: Student Health Guide

A static website (HTML and CSS only, no JavaScript) with a symptom checker, health topics, student services, trusted sources and a Get help page.

General health information only. It is not medical advice or a diagnosis.

## Deploy with GitHub Pages
1. Create a new repository on GitHub (for example `campus-care`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then save.
5. After a minute your site is live at `https://YOUR-USERNAME.github.io/campus-care/`.

## Deploy from the command line
```
git init
git add index.html README.md
git commit -m "Add Campus Care site"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/campus-care.git
git push -u origin main
```

## Keeping it accurate
Check hospital details, emergency numbers and helpline numbers in the Get help section regularly, and have a qualified health professional review the medical content.
